# Vanta Obfuscator

Vanta is a Luau source-protection platform in active development. The workspace contains a React dashboard, Express API, Discord bot, PostgreSQL schema, and an engine package. The API image builds Roblox's official Luau compiler frontend from source.

## Official Luau parser/compiler

Every API build validates its input and generated output with `luau-compile` from the official [`luau-lang/luau`](https://github.com/luau-lang/luau) repository. The official compiler frontend calls `Luau::Parser::parse`; generated bytecode is discarded, and submitted scripts are never executed. See the official [build instructions](https://github.com/luau-lang/luau#building) and [compiler implementation](https://github.com/luau-lang/luau/blob/master/CLI/src/Compile.cpp).

The API uses `LUAU_COMPILE_PATH` (default `luau-compile`). If the binary is missing, builds fail with HTTP 503 rather than silently pretending that the custom scanner is the official parser. Docker builds the official compiler as part of the API image.

## Current functionality

- Dashboard with Luau editor, build submission, output display and copy.
- One build action runs the pinned Obscura `PARANOID` VM pipeline, including its parser, bytecode compiler, encrypted bytecode and generated VM runtime. The VM path is Obscura's virtualized execution strategy; it is not a sequential run of every native AST layer. Vanta validates both submitted source and generated output with the official Luau compiler.
- The worker does not silently return original source when Obscura rejects syntax or fails; the build is marked failed with a diagnostic. Obscura supports a subset of Luau syntax, so some newer or less common Luau constructs may not be accepted.
- Obscura is pinned to commit `742770554151d82c6a12ae6e24a0e47471bc467c`; attribution and license are in `THIRD_PARTY_LICENSES/`.
- Account registration/login with scrypt password hashes and hashed, expiring bearer sessions.
- Public or invite-only registration (`ACCESS_MODE`), bootstrap administrator email, one-time invite creation endpoint.
- API key creation, listing and revocation; raw keys are only returned once.
- PostgreSQL-backed build history and output retrieval.
- Discord OAuth account linking, bot `/status`, `/obfuscate`, `/profile`, `/stats` and `/help` commands.
- Docker Compose definitions for API, web, PostgreSQL, Redis and an optional Discord bot profile. The web container proxies `/api/*` to the API so the browser uses a same-origin API URL.
- Render Blueprint for the API, isolated worker, web dashboard, Discord bot, PostgreSQL and private Redis-compatible Key Value service.
- Render deployment walkthrough in `DEPLOY_RENDER.md`.

## Important limitations

The repository is a **self-hostable Vanta deployment package**. It includes a Render Blueprint (`render.yaml`) and a step-by-step Render guide (`DEPLOY_RENDER.md`); creating the hosted service still requires your own GitHub, Render, and (if enabled) Discord accounts. Obscura is integrated as the current engine foundation so it can be improved or replaced later. Its parser and VM have documented Luau compatibility limits; test protected output in Roblox Studio before relying on it. The build worker runs in a separate non-root container. In the included Docker Compose deployment it uses a read-only root filesystem with a temporary filesystem for parser inputs, drops Linux capabilities, and has CPU/memory/PID limits. On Render, network isolation and resource limits depend on the selected Render service plan and settings. This is container-level isolation, not a per-job VM or a substitute for a formal security review. Discord role synchronization, billing/entitlements, detailed admin management, observability, automated backup/restore, live Roblox Studio runtime verification, and a full security review remain outstanding. You must provide your own production secrets, Discord application, domain and hosting provider; this package cannot create or operate those external accounts for you.

Obfuscation is not cryptographic security. Only submit code you own or are authorized to protect.

## Requirements

- Node.js 22+
- pnpm 9+
- Python 3.11+ and Git for local Obscura bootstrap
- Docker and Docker Compose (recommended)
- CMake and a C++17 compiler if building Luau locally

## Local development

1. Copy `.env.example` to `.env` and set a strong base64url-style `POSTGRES_PASSWORD` (letters, numbers, `_`, `-` avoid URL-encoding issues). Set `BOOTSTRAP_ADMIN_EMAIL` to the email that should receive the initial administrator role. For invite-only registration, set `ACCESS_MODE=invite_only`; the bootstrap administrator can create invitations from Settings after signing in.
2. Install dependencies: `pnpm install`.
3. Run `pnpm bootstrap:obscura` to fetch the pinned Obscura source, then install the official Luau toolchain and ensure `luau-compile` is on `PATH`, or set `LUAU_COMPILE_PATH`.
4. Start PostgreSQL and Redis: `docker compose up -d postgres redis`. Their ports are bound to `127.0.0.1` for local development only.
5. Run `pnpm typecheck`, `pnpm test:engine`, and `pnpm test:luau`.
6. Start the worker with `pnpm dev:worker` after setting `OBSCURA_ROOT` if your checkout is outside `vendor/obscura`. Start API and web in separate terminals: `pnpm dev:api` and `pnpm dev:web`.
7. Start the Discord bot after configuring its credentials: `pnpm dev:bot`.

## Docker deployment

Set all required values in `.env`, then run:

```sh
docker compose up --build -d
```

The dashboard is served on port `8080`; API is on `4000`. The optional bot is enabled with:

```sh
docker compose --profile bot up --build -d
```

For the bot's `/profile` and `/stats` commands, create an administrator account, create an API key for it in the dashboard, and set that key as `VANTA_BOT_API_KEY`. Set the Discord OAuth redirect URI to the public API URL plus `/api/discord/oauth/callback`, and configure the same URI in the Discord application.

For Render deployment, follow `DEPLOY_RENDER.md`. The dashboard proxies API requests through its web origin; Render service references configure the private API upstream. For other hosts, set `API_HOST` in the web container, keep PostgreSQL and Redis private, and configure `WEB_ORIGIN`, `WEB_APP_URL`, and (when using a custom domain) `DISCORD_REDIRECT_URI`.

## Repository layout

- `apps/web`: dashboard/editor and account pages
- `apps/api`: build/auth/API/Discord OAuth routes and official compiler integration
- `apps/bot`: Discord slash-command bot
- `apps/api/migrations`: PostgreSQL schema (applied at API startup)
- `packages/shared`: shared contracts
- `packages/engine`: TypeScript bridge, Python adapter and official Luau compiler validation
- `tests/luau`: official parser fixtures
- `scripts`: parser test runner

## Verification status

The repository includes CI checks for TypeScript builds, the Obscura VM adapter and official Luau parser fixtures. A deployment is not considered verified until those checks pass in CI and a real Render deployment completes a successful build tested in Roblox Studio. No hosted Vanta instance or Discord application is created by this repository.
